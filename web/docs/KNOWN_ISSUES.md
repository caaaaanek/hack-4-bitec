# Відомі обмеження

- Бриф `docs/DESIGN_BRIEF.md` тепер у репозиторії; звірку див. у розділі «Відповідність брифу» в `docs/DESIGN_SYSTEM.md`.
- Стани hover, active на сторінці `/design` не зафіксовані статично: їх видно лише при взаємодії.
- Playwright-перевірка запускається лише в Chromium; Firefox і WebKit не перевірялися.
- Візерунки зрілості для друку перевірено лише за CSS (print.css), фізичний друк не тестувався.
- Шрифт Inter підключено через власний `fonts.css` (лише cyrillic і latin), бо пакет не має окремих CSS по піднаборах.
- Дашборд не показує окремих фактів, тому кількості фактів («45 з 100 (45%)») видно лише на `/explain` у режимі «Факти».
- Кнопка «Переглянути результати підрозділу» на екрані подяки в демо перемикає роль на респондента, бо опитування відкривається за посиланням без входу.
- Заглушки `/manage`, `/surveys`, `/checklist`, `/audit` лише пояснюють майбутній вміст.
- Матриця перевірки не проходить анкету з клавіатури (Tab, стрілки): це покрито лише тестами компонентів і ручною перевіркою.
- Дві теми: темна за замовчуванням, світла у шапці. Скріншоти у світлій темі знімаються лише на 1280 для `/`, `/explain`, `/me`, `/s/demo`; решта екранів у світлій темі перевірена контрастом токенів, а не очима.
- Селектор періоду й кнопка «Експорт» у шапках сторінок не додані: екранів динаміки й звітів ще немає (заглушки). Теплокарти й ComparisonBars у проєкті немає, тож тематизовано gauge, радар, лінію динаміки, кроки зрілості.
- Кнопка сповіщень показує, що нових сповіщень немає (синтетичні дані без подій). Іконка довідки веде на `/explain` і прихована для ролей без доступу туди.
- Підписи й заголовки карток 12 px за вказівкою щодо щільності (раніше мінімум 14 px).
- Друк світлий завдяки дублю світлих токенів у `@media print`; фізичний друк не тестувався.
