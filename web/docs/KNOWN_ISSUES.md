# Відомі обмеження

- `docs/DESIGN_BRIEF.md` відсутній у репозиторії (ні в `web/docs`, ні в гілках), тому роботу виконано за принципами з промту.
- Стани hover, active на сторінці `/design` не зафіксовані статично: їх видно лише при взаємодії.
- Playwright-перевірка запускається лише в Chromium; Firefox і WebKit не перевірялися.
- Візерунки зрілості для друку перевірено лише за CSS (print.css), фізичний друк не тестувався.
- Шрифт Inter підключено через власний `fonts.css` (лише cyrillic і latin), бо пакет не має окремих CSS по піднаборах.
